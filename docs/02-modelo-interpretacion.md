## Niveles de evidencia

Cada afirmación del informe se etiqueta internamente por cuánto la sostiene el dato:

- **E1** — se lee directamente de la puntuación
- **E2** — inferencia razonable a partir de una combinación
- **E3** — hipótesis para contrastar con la persona
- **E4** — marco teórico general, no personalizado

Los pasajes E3 se redactan como pregunta o hipótesis, nunca como afirmación cerrada.

## Inferencias prohibidas

No inferir a partir del test: capacidad intelectual, salud mental, idoneidad para un
puesto, rasgos clínicos, ni predicciones de rendimiento.
